# xe125-respiratory-rate

Bench-to-production respiratory-rate measurement using the Acconeer XE125/XM125.

**Status:** Accepted for implementation by explicit user instruction. The initial implementation is
bench-only and must not promote radar output into the alarm path.

Artifacts:

- `proposal.md` — why this change exists and its scope.
- `specs/xe125-respiratory-rate/spec.md` — normative requirements.
- `design.md` — architecture and decisions.
- `tasks.md` — ordered implementation tasks and verification contracts.
