Confirmations, three weights

1 · Inline

Reversible, no data loss. Confirms in place, undo available.

2 · Dialog

Recoverable cost, or a real-world consequence such as a sample gap. States what happens, then a plain confirm.

3 · Typed

Unrecoverable. Lists consequences and requires the object's name typed. Never adjacent to a routine control, never bound to a keystroke.
