Direction C — Flowpath

Health is a property of an edge. Four edge hues, four stroke grammars — unknown is a violet severed pipe.

Rationale

Every failure in the brief is the same shape: the record stops arriving somewhere, and nothing announces it. So this direction stops modelling the machine as a list of subsystems and models it as the path the record takes — sensor, radio, collector, spool, database, aggregate, correlation, report. Health is not a badge attached to a component. It is a property of an edge: is the record moving through here, and how fast.

That reframing gives the third state a natural form. Unknown is a severed pipe — a violet hairline with a visible cut in it. The hue takes you to the break from across a room; the cut is what tells you it is a break rather than a slow link, and it keeps telling you that in greyscale. You can trace it left to find the cause or right to find what it costs: a stale backup here is not an amber badge beside a green database, it is the last edge in the chain, cut, with the report hanging off the end of it.

Each of the four edge states owns a hue and a stroke grammar at the same time. Flowing is mint and continuous. Impaired is amber and long-dashed. Losing is rose, solid, and the heaviest stroke on the canvas. Severed is violet, hairline, and broken. Weight rises with consequence, so the ranking survives losing colour entirely.

It is keyboard-first, because the graph is a path and paths are walked. j and k move upstream and downstream, and the inspector follows. Everything is equally reachable by tab and click; the keys are an accelerator, never the only route.

Why flowing gets a colour. A graph where only the faults are coloured shows you the breaks but not the shape of the thing that is working, and reading this console is mostly the second task: following a healthy path until it stops. Mint marks every edge the record is actually moving through, which makes the cuts read as interruptions in something rather than as isolated badges. It is blue-shifted on purpose — a true green sits on top of amber under deuteranopia.

The metric hue stays separate from all four. Cyan #77C7E8 is only ever a rate plotted over time, never a state, and no status hue is ever reused as a chart category. Grey is left for one thing: a source declared absent, where there is no edge to have a state.

Five vocabularies

Each has its own shape. Two may appear side by side; they are never merged.

1 · Health assertion — is the record moving through here?

Three values, drawn as a pipe. Never shown without a freshness reading.

Flowing ✕ Lost ▲ Impaired Severed — Not configured
With freshness Flowing 41s ago2m Severed by age Severed 2h 42m ago10m Last known: failing at 02:14 — sensor disconnected during pairing.

Current confidence and last known outcome are separate facts and both stay on screen. An edge going dark does not erase what last came through it, and the reason is the only part that can be acted on. An edge whose own check is older than its expected interval severs itself; nobody has to decide that.

2 · Lifecycle — what happened to a piece of work?

A filled pill, no pipe and no cut. A run is not an edge.

Queued · position 2 Running · 04:12 Succeeded · 06:41 Failed · rate limit Cancelled by operator

A finished upload is not flowing. A queued job is not severed. A failed run severs an edge only if the thing it should have produced is now stale.

3 · Process state — systemd's own words

Reported, never interpreted.

active (running) activating (start) failed (Result: exit-code) inactive (dead)
active (running)  +  Severed  — the process is alive and its outgoing edge is cut. Both are true. Collapsing them is how tonight's failure would have stayed invisible.

4 · Operator suppression

A severed edge can be muted with an expiry and a named operator. The mute stops the reporting, never the attempts, and it is never re-badged as configuration.

⊘ Muted to 09 Aug · operator ⊘ Muted 6 more nights · operator

5 · Configuration — no edge to draw

A source that does not exist gets a dotted stub that terminates in open space, because there is no downstream to reach. Excluded from the rollup and from the report.

— Not configured Declared absent 02 June 2026 — no BP cuff owned.

The distinction that protects the third state. A configured ring that went unworn is a muted severed edge with an expiry. A device that does not exist is a stub. If every optional thing renders as a cut pipe, cuts become wallpaper and the graph stops working.

Confirmations, proportionate to consequence

Three weights. Reversible actions confirm inline. A recoverable cost gets a plain dialog. Anything unrecoverable lists what will be lost and requires the object's name typed.
