Attempt timeline

Windows drawn as pipe. Where no attempt was made, no pipe is drawn.

The pipe is the argument

A conventional attempt log lists what happened. The failure this product has to survive is the opposite: what did not happen, at the times it was supposed to. So this component draws the expected windows as a pipe, left to right, and simply does not draw a pipe where no attempt was made. A run of red is a pipe carrying failures. A run of nothing is a pipe that was never laid.

The verdict is a single word before any rows, because silent and failing are different diagnoses with different repairs. Failing gives you an error to read. Silent gives you nothing, which is exactly why it needs to be stated rather than inferred from an empty table.
