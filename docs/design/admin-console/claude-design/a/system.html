Direction A — Service Mode

Modelled on the technician screens behind a bedside patient monitor.

Rationale

Hospital equipment has already solved the problem this console has: a person under time pressure has to establish, from across a room, whether an instrument can be trusted. The answer is a rigid frame. Fields occupy fixed positions and never reflow, so the eye learns where to look rather than reading the screen. Every value carries its unit and the time it was observed. Alarm priority is a formal, bounded vocabulary rather than an adjective.

This direction takes that literally. Every health state carries a hue and a wash behind it, on the same alarm-priority terms a monitor uses — so a subsystem's condition is readable from the doorway, not only from the chair. Grey is reserved for ordinary text and for something declared absent, which is the one state with nothing to assert. The third state — we have not checked, so we do not know — sits in the palette beside high, medium and low rather than below them, because on this product an unverified backup is a more dangerous object than a failed one.

Colour is the first read; it is never the only read. Every one of the six states above carries a hue, and every one also carries a wash behind it so the state is legible from across a room rather than only at the chip. Grey is reserved for two things and two things only: ordinary text, and something declared absent — the one state that genuinely has nothing to say.

On the green. Healthy is mint #55D6A0 rather than a leaf green, because a blue-shifted green holds its distance from amber under deuteranopia, where a true green does not. It is also never used alone: OK always appears as ✓ OK with a freshness reading beside it, so an ambiguous hue still resolves to an unambiguous statement. Sparklines, bar fills and successful attempt ticks all use the same mint, so a healthy quantity and a healthy status share one colour and the eye only has to learn it once.

Five status vocabularies

Never collapsed into one another

1 · Health assertion — can this be relied on right now?

Three values, and only these three. A boxed monospace chip. Health assertions never appear without a freshness reading beside them.

✓ OK ▲ Fault · High ■ Fault · Med ● Fault · Low ? Unknown
With freshness ✓ OK 4m ago10m Degraded by age ? Unknown 2h 42m ago10m Last known: failing at 02:14 — sensor disconnected during pairing.

Rule. Current confidence and last known outcome are two separate facts and both are shown. The console losing sight of a thing does not erase what it last saw, and the reason is the only part the user can act on.

2 · Lifecycle — what happened to this piece of work?

A left bar, no box, sentence case. Structurally different from a health chip so the two can sit side by side without being read as one thing.

Queued · position 2 Running · 04:12 elapsed Succeeded · 06:41 Failed · rate limit Cancelled by operator

Not health states. A completed upload is not OK. A queued job is not a question. Lifecycle answers "what happened to this run", health answers "can I trust this subsystem".

3 · Process state — what systemd says, verbatim

Reported, not interpreted. A unit can be active (running) and still be a health fault, which is exactly the case this console exists to surface.

active (running) activating (start) failed (Result: exit-code) inactive (dead)
active (running)  +  ▲ Fault · High   — the collector process is alive and has written nothing for nine hours. Both facts are true and both are shown.

4 · Operator suppression

Expected silence is muted with an expiry, by a named operator. A mute is never re-badged as configuration, and it never becomes permanent by default.

⊘ Muted until 2026-08-09 · operator ⊘ Muted 6 more nights · operator

5 · Configuration — declared absent

Something the user does not own, or has declared out of use. Excluded from rollups. Visible, so the registry stays honest, but quiet.

— Not configured Declared absent 2026-06-02 — no BP cuff owned.

The distinction that protects the third state. A configured ring that simply went unworn last night is a benign unknown, muted with an expiry. A device the user does not own is not configured. If every optional thing renders as a question mark, the question mark becomes wallpaper.

Confirmations, proportionate to consequence

Three weights. Reversible actions confirm inline. Actions with a recoverable cost use a plain dialog. Actions that destroy something unrecoverable require the object's name to be typed, and list what will be lost.

Delete therapy session?

Thursday 14:00 with R. Alvarez, weekly. The session is removed from the schedule. Past journal entries that reference it are unaffected.

This can be undone from the audit log for 30 days.

▲

Revoke API key “home-assistant”?

Revocation takes effect immediately and cannot be undone. A new key can be issued, but this one can never be restored.

  • Any client presenting this key starts receiving 401 at once.
  • The Home Assistant bridge stops writing heart-rate samples until it is re-keyed.
  • Samples arriving during the gap are not buffered. They are lost.
▲

Restart aw2-collector-chest?

The chest strap must re-pair after the restart. Pairing typically takes 40–90 seconds and has failed on 3 of the last 20 attempts.

  • Estimated sample gap: 1–2 minutes, longer if pairing fails.
  • Tonight's HRV baseline is computed from a full night. A gap invalidates it.
