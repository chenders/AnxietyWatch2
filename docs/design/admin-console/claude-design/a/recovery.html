All copies are on the same NVMe as the database. A drive failure loses the record and every backup of it at the same moment.

Restore

Destructive

Restoring into the live cluster replaces the system of record with the chosen archive. Everything written since that archive is gone.

Restoring into a scratch cluster, by contrast, is safe and is what the verification job does. It is a separate, unfenced control.
