Three design directions, each a complete design system delivered as vanilla HTML and CSS. One stylesheet per direction, tokens on :root, semantic class names, no inline styles except values computed per datum (a bar width, a sparkline point), no build step and no dependencies. Each direction takes a different position on the hardest requirement in the brief — making "we don't know" impossible to read as "healthy":

  • A · Service Mode makes unknown violet, on alarm-priority terms alongside high, medium and low.
  • B · Preflight makes unknown periwinkle, and draws it as an empty signature box.
  • C · Flowpath makes unknown violet, and draws it as a visible cut in a pipe.

In all three, colour is the first read and never the only one: every state also carries a glyph, a fill polarity or a stroke pattern that survives greyscale and every dichromacy. Grey is reserved for the one state with nothing to assert — something declared absent.
