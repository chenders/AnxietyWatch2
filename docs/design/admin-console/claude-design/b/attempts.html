Run sheet

One box per expected window. A cross is a failure; an empty box is a silence.

Why the empty box is the whole idea

This direction draws every expected collection window as a box that either got a mark or did not. A run of crosses is a failure: something tried and something can be read about why. A run of empty boxes is worse, and it is what a dead source actually looks like — no error, no entry, no exception. Nothing wrote in the box.

A conventional log view cannot show this, because it lists what happened. The thing that needs showing is what did not happen, at the times it was supposed to. So the verdict is stated in a word before any rows, and the row list is secondary.
