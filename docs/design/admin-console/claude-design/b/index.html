Direction B — Preflight

An inspection checklist rather than a dashboard. Every assertion is a line item that is signed by a named prober, explicitly open, explicitly struck as not applicable, or visibly unsigned. Four dispositions, four hues, four stamp shapes: teal signed, rose open, amber advisory, periwinkle unsigned. The colour gets you to the right row in a second; the empty box is what still tells you the truth once the colour is gone.
