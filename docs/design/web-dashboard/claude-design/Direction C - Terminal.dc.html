DIRECTION C — TERMINAL

The bet: the person reading this at 3 a.m. is the person who wrote the daemon, and the fastest interface for them is the one that looks like the tool they already trust. One monospace grid, one column of panels, every panel headed by the command that produced it, every value printed as key=value with its units and its timestamp. Navigation is keyboard-first — digits jump screens, d simulates sensor loss, t swaps theme, ? lists the map — and the mouse is a fallback, not the design. Because everything is one typeface at one width, the only variables left for meaning are colour, glyph and position, so the system spends them carefully: null is periwinkle-hatched, alarms are ranked by frame weight, and nothing is decorative.
